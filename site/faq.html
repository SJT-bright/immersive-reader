QUESTIONS, WITH CONTEXT

开始前，
把问题说清楚。

沉浸阅读器是什么，适合哪些使用场景？

它是 SJT-bright 的个人本地电子书阅读项目。适合想在雨窗、雪景或书桌环境中读自己 EPUB / TXT，并同时做划线笔记、听背景音乐和记录阅读习惯的人。源码可下载并在本机运行。

支持哪些文件？能读扫描 PDF、MOBI 或加密书吗？

当前支持可重排 EPUB、TXT 和具有文字层的 PDF。PDF 导入提取文字，不保留原页面图片与版式；扫描 PDF 需先用其他工具 OCR。固定版式 / DRM 加密书、MOBI / AZW3 不是当前承诺支持的格式。

如何在 Mac、Windows 或 Linux 启动？

解压完整源码，Mac 运行 sh start.sh 或 start.command；Windows 运行 start.bat；Linux 运行 python3 scripts/serve.py --port 8940。打开 http://127.0.0.1:8940/，保持服务运行。需要现代 Chrome / Edge，以及 Node.js 或 Python；无需 npm 安装。macOS 已有实际验收，Windows / Linux 启动入口尚未分别实机验收。

无需账号是否意味着完全没有联网？

阅读器没有用户账号；本地解析、书库、内置音源和环境声不需要外部读书服务。网易云 / QQ 官方播放器和外部链接需要联网，第三方服务可收到相应请求。公开项目主页仅用于介绍，不接收个人书籍。

书籍、进度和笔记存在哪里？会自动云同步吗？

存于本机浏览器 IndexedDB，并由本机服务镜像至 SQLite。默认磁盘目录为当前用户主目录下的 Library/Application Support/immersive-reader-app/library。不同浏览器或地址的缓存互相独立，迁移前请导出备份。当前没有账号式跨设备云同步。

立体双页是否还能选字、搜索和记笔记？

可以。双页视觉基于真实 DOM 正文、透视和纸面光照，是 2.5D 近似；文字没有被烘焙成图片。选字、搜索、划线与原文定位仍可使用。

自动阅读手动翻页后会停止吗？

1.9.3 中手动翻页会重置自动阅读的等待时间并继续。换书、回到首页、进入后台、按 Escape 或读到书末会暂停；刷新不会自行开启自动阅读。

能设置自己的图片和视频、关闭雨雪吗？

可以上传本地图像或浏览器支持的视频，视频静音循环；可切换固定、时段和定时轮换。选择晴天、关闭天气或使用专注预设可减少画面干扰，也尊重系统减少动态效果。

有哪些背景声音，内置音乐从哪里来？

十种环境声由浏览器程序合成：雨、雪、海浪、山风、溪流、篝火、虫鸣与三种色噪。六首内置音乐同样由项目生成脚本合成，没有取用他人的采样录音；可另行导入自己的本地音乐。

网易云和 QQ 音乐是否保证所有歌曲都能播放？

不保证。项目使用官方外链播放器或官方打开入口，播放受歌曲授权、平台及浏览器环境影响；不提供会员解锁、音频代理或非官方账号接口。本地音频是可独立使用的路径。

阅读进度与阅读时长有什么区别？

进度按实际显示过的书页区间记录，不把跳到末页直接当作读完整本；目录同时显示各章已读比例。时长记录当前活跃阅读计时，提供目标、热力图和成就，不等同于对阅读理解程度的测量。

如何备份与迁移，笔记能单独导出吗？

书架面板可导出包含全部书籍和媒体的完整 JSON 备份；恢复可选择合并或覆盖，并先保存恢复前快照。笔记面板另可按书导出 Markdown，包含划线、心得和书签。

项目是否开源，能否商用整个雨窗版本？

原创代码在 MIT 许可下开源；第三方组件保留原许可。当前 js/rain-shaders.js 含 Heartfelt 衍生效果，适用 CC BY-NC-SA 3.0。它带非商业限制，因此完整雨窗包不是全部采用 OSI 开源许可证，也不能一概视为可商用。请查看 LICENSE-NOTES.md。

这是微软的 Immersive Reader 吗？

不是。本项目的完整标识是 SJT-bright/immersive-reader（沉浸阅读器），是独立的本地电子书阅读项目；与 Microsoft / Azure Immersive Reader 无隶属关系。
